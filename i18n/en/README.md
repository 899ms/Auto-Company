# English Resources

This directory contains the English autonomous-loop prompt, all 14 agent definitions, and the `team` and `github-explorer` skills.

Resolve paths in these resources from the repository root, not from this directory. Role and skill references keep their canonical paths; the runtime language table selects their English counterparts under `i18n/en/` when the original source has not been customized. Shared skills, project outputs, and memory files keep their original repository-root paths. See the [language guide](../README.md) for configuration and fallback behavior.
